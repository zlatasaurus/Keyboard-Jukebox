DJ mode
Load tracks in Keyboard Jukebox DJ (taskbar, bottom of the screen). These shortcuts then work from any app. Commands work even with Sounds OFF.
Setup: run loopMIDI with a port named "Keyboard Jukebox", pick it above, hit Install Mixxx mapping, then in Mixxx go to Preferences > Controllers > Keyboard Jukebox, tick Enabled and load the "Keyboard Jukebox" mapping. Commands work even with Sounds OFF.
